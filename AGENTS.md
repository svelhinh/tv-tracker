# TV Tracker — Agent Context

Prototype Flutter privé pour tester une alternative simple à TV Time.

## Scope actuel

- Flutter mobile
- Riverpod
- Pas d'auth
- Pas de backend
- Pas de base locale tant que ce n'est pas demandé
- Pas d'intégration TMDB tant que ce n'est pas demandé
- Pas de design final

## Règles de code

- Code simple et lisible.
- Architecture légère.
- Ne pas sur-développer.
- Ne pas ajouter de features non demandées.
- Garder les providers Riverpod simples.
- Expliquer les changements importants.
